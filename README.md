# Dart Programming Group Assignment

## Course

Mobile Application Development

## Assignment Overview

This project contains solutions to ten Dart programming questions covering the fundamental concepts of the Dart programming language. Each question has been implemented in a separate Dart file with clear comments and readable code.

## Project Structure

* question1_variables.dart
* question2_operators.dart
* question3_control_flow.dart
* question4_loops.dart
* question5_functions.dart
* question6_bank_account.dart
* question7_inheritance_mixins.dart
* question8_collections.dart
* question9_exception_handling.dart
* question10_async_programming.dart

## Topics Covered

### Question 1

Variables and Data Types

### Question 2

Operators and Expressions

### Question 3

Control Flow (if, else if, else, switch)

### Question 4

Loops (for, while, do-while, for-in)

### Question 5

Functions, Named Parameters, Optional Parameters, Arrow Functions, and Closures

### Question 6

Object-Oriented Programming, Classes, Constructors, Encapsulation, Getters

### Question 7

Inheritance, Abstract Classes, Method Overriding, Mixins

### Question 8

Collections (List, Set, Map) and Functional Methods (`where()`, `map()`, `fold()`)

### Question 9

Exception Handling, Custom Exceptions, try, on, catch, finally

### Question 10

Asynchronous Programming using Future, async/await, Future.wait, Streams, async*, yield, and await for

## How to Run

1. Install the Dart SDK.
2. Open a terminal in the project folder.
3. Run any question using:

```bash
dart run question1_variables.dart
```

Replace the filename with the question you want to run.

## Conclusion

This assignment demonstrates the core features of the Dart programming language required for Mobile Application Development, including procedural programming, object-oriented programming, collections, exception handling, and asynchronous programming.
